# Практика 1. Машина через веб-консоль

## Создание виртуальной машины

1. Выполнен вход в Yandex Cloud и выбран каталог default.
2. Открыт сервис Compute Cloud.
3. Открыт раздел «Виртуальные машины».
4. Выбрано создание новой виртуальной машины.
5. Выбран загрузочный образ Ubuntu 24.04.
6. Выбрана зона доступности ru-central1-d.
7. Для загрузочного диска выбран тип HDD и размер 25 ГБ.
8. Открыта пользовательская конфигурация вычислительных ресурсов.
9. Установлено 2 vCPU, гарантированная доля 20 % и 2 ГБ RAM.
10. Включён режим прерываемой виртуальной машины.
11. Выбрана подсеть default и автоматическое назначение публичного IPv4-адреса.
12. Выбран доступ по SSH и добавлен публичный SSH-ключ.
13. Указано имя shrainer-06-web-manual.
14. Добавлена метка created-by=console.
15. Нажата кнопка создания виртуальной машины.
16. Проверено, что виртуальная машина перешла в состояние Running.

## Настройка созданной машины

17. Скопирован публичный IPv4-адрес виртуальной машины.
18. Выполнено подключение к виртуальной машине по SSH.
19. Обновлён список пакетов.
20. Установлен веб-сервер nginx.
21. Проверено состояние службы nginx.
22. Стартовая страница nginx изменена в соответствии с вариантом 06.
23. Проверено отображение строки netlab on shrainer-06-web-manual.
24. Работа страницы проверена через публичный IP-адрес в браузере.
