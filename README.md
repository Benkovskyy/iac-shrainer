# iac-shrainer

Учебный репозиторий по дисциплине «Инфраструктура как код».

В репозитории представлены практические и самостоятельные работы по созданию, настройке и автоматизации облачной инфраструктуры в Yandex Cloud с использованием Bash, cloud-init, GitLab CI/CD и Terraform.

## Параметры варианта

- Вариант: `06`
- Префикс ресурсов: `shrainer-06`
- Зона: `ru-central1-d`
- Подсеть: `10.16.1.0/24`
- Операционная система: Ubuntu 22.04 LTS
- Порт приложения: `8018`
- Слово на веб-странице: `netlab`
- Окружение: `dev`

## Структура репозитория

### Практическая работа № 1 — work-01

Создание и удаление облачной инфраструктуры Yandex Cloud с использованием команд CLI и Bash-сценариев.

Содержит:

- `create.sh` — создание инфраструктуры;
- `destroy.sh` — удаление созданных ресурсов;
- `commands.sh` — журнал использованных команд;
- `notes.md` — заметки по выполнению работы.

### Практическая работа № 2 — work-02

Автоматизированное развёртывание виртуальной машины и настройка веб-сервера nginx с использованием cloud-init.

Содержит:

- `create.sh` — автоматизированное создание стенда;
- `destroy.sh` — удаление ресурсов;
- `cloud-init.tpl.yaml` — шаблон первоначальной настройки виртуальной машины.

Создание стенда:

`bash work-02/create.sh`

Удаление стенда:

`bash work-02/destroy.sh`

### Самостоятельная работа № 1 — hw-01

Автоматизация создания, проверки и удаления облачной инфраструктуры с использованием Bash-сценариев.

Содержит:

- `create.sh` — создание стенда;
- `destroy.sh` — удаление стенда;
- `check.sh` — проверка работоспособности;
- `cloud-init.tpl.yaml` — шаблон настройки виртуальной машины;
- `расхождения.md` — журнал обнаруженных расхождений.

### Практическая работа № 3 — CI/CD

Настройка автоматизированных проверок проекта с использованием учебного GitLab CI/CD.

Основные файлы в корне репозитория:

- `.gitlab-ci.yml` — конфигурация CI/CD;
- `.gitignore` — исключение служебных и секретных файлов;
- `README.md` — документация проекта.

Выполненные задачи:

- Настроен CI/CD-пайплайн.
- Настроены проверки shell-скриптов с использованием ShellCheck.
- Организовано хранение секретных данных в переменных GitLab.
- Проверена работа пайплайна на учебном раннере.

При изменении только документации проверка ShellCheck не запускается.

### Практическая работа № 4 — work-04

Создание и управление облачной инфраструктурой Yandex Cloud с использованием декларативных манифестов Terraform.

Содержит:

- `versions.tf` — настройка Terraform и провайдера Yandex Cloud;
- `main.tf` — описание сети, подсети, виртуальной машины и дополнительного диска;
- `cloud-init.tpl.yaml` — первоначальная настройка Ubuntu и nginx;
- `.terraform.lock.hcl` — фиксация версии провайдера и контрольных сумм.
