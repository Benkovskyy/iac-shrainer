# iac-shrainer

Учебный репозиторий по дисциплине «Инфраструктура как код».

В репозитории находятся практические и самостоятельные работы по развёртыванию инфраструктуры в Yandex Cloud и её автоматизации.

## Структура репозитория

### work-01

Практическая работа № 1.

Содержит:
- create.sh — создание инфраструктуры;
- destroy.sh — удаление созданных ресурсов;
- commands.sh — журнал использованных команд;
- notes.md — заметки по выполнению работы.

Префикс ресурсов: shrainer-06.

### work-02

Практическая работа № 2.

Содержит:
- create.sh — автоматизированное создание стенда;
- destroy.sh — удаление ресурсов стенда;
- cloud-init.tpl.yaml — шаблон cloud-init.

Параметры варианта:
- префикс: shrainer-06;
- слово: netlab.

Создание стенда:

    bash work-02/create.sh

Удаление стенда:

    bash work-02/destroy.sh

### hw-01

Самостоятельная часть работы по автоматизации инфраструктуры.

Содержит:
- create.sh — создание стенда;
- destroy.sh — удаление стенда;
- check.sh — проверка работоспособности;
- cloud-init.tpl.yaml — шаблон cloud-init;
- расхождения.md — журнал обнаруженных расхождений.
